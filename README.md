# Telegram Bot для Margiana Logistic Services

Telegram-бот для отслеживания логистических заказов и автоматических уведомлений.

## Функции

- 📋 Просмотр активных заказов
- ✅ Завершенные заказы за 30 дней
- 🔍 Фильтрация заказов по статусу
- 📷 Заказы без фото загрузки
- 📅 Предстоящие события
- 📄 Генерация PDF отчетов
- 🔔 Автоматические уведомления
